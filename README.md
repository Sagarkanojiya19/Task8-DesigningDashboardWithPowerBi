# 📊 Online Sales Dashboard using Power BI

This repository contains a Power BI dashboard project built on an **Online Sales** dataset to analyze key performance indicators in an e-commerce environment.

---

## 📁 Files Included

- `Task8.pbix` – The Power BI dashboard file.
- `Online Sales Data.csv` – The dataset used to create the dashboard.

---

## 📌 Objective

The purpose of this dashboard is to:

- Analyze online sales revenue and trends
- Monitor product category performance
- Examine regional and payment method distributions
- Provide actionable insights for sales strategy

---

## 🔍 Dataset Overview

The dataset includes the following key columns used in the dashboard:

- `Date` – The transaction date
- `Product Category` – Category of the sold item
- `Product Name` – Specific product involved in the transaction
- `Units Sold` – Quantity sold per transaction
- `Unit Price` – Price per unit
- `Total Revenue` – Revenue generated per transaction
- `Region` – Geographic location of the sale
- `Payment Method` – Payment method used by the customer

---

## 📊 Dashboard Features

- **Revenue Overview**: Total revenue and units sold KPIs
- **Category Analysis**: Sales performance across product categories
- **Trend Analysis**: Monthly revenue and unit sales trends
- **Regional Breakdown**: Sales performance by region
- **Payment Method Analysis**: Distribution of revenue by payment methods

---

## 🛠 Tools & Technologies

- Power BI (Data modeling, visualization)
- CSV file as data source
